For this lab, I compared sorting the same 10,000 unique integers using a native C++ plugin, a managed C# plugin, and a C# MonoBehaviour in Unity. After 100 trials per method, the native plugin averaged 0.341729 ms per sort, the managed plugin averaged 0.715716 ms, and the MonoBehaviour averaged 0.732632 ms. The native C++ plugin was the fastest, taking less than half the time of either C# method in this test. The two C# methods performed similarly, which makes sense because both used Array.Sort, while the native plugin used std::sort. Each trial started with the same unsorted data, and copying and Console logging were excluded from the timing. All three methods produced identical sorted results. This showed me how native plugins can improve performance for some tasks, although the benefit depends on the implementation and the environment where the code runs.
